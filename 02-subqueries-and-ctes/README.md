# Subqueries, CTEs and Temporary Tables

Module 11 exercises over AdventureWorks OLTP.

The script covers product membership subqueries, current employee departments via correlated subqueries and a CTE, local/global temporary tables, a 2011 order-date filter, and string manipulation with `SUBSTRING`.

Run in a dedicated SQL session after selecting AdventureWorks. The temporary-table statements use `CREATE TABLE` and can fail if rerun in the same session while the tables still exist. Source retained unchanged; no runtime result is claimed.
